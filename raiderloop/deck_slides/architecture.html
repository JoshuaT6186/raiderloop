HOW IT'S BUILT

A real, working technical stack — not a mockup.

App

React Native, built for iOS with an architecture portable to Android. Currently distributed via TestFlight.

Backend

Firebase Cloud Functions, with Firestore caching results on a schedule matched to how fast each data type actually changes — from 3 hours for news to 30 days for a stadium photo.

Data & privacy

Every data source is public. No student accounts, no eRaider dependency, and no personal data stored on any server today.
